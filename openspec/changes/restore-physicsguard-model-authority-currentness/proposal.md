## Why

PhysicsGuard source, tag, and installed package identify v0.11.3, but the repository only records an upgraded FlowGuard policy and has no observed model-system authority. Two older maintenance changes also retain final unchecked closure items. Feature evidence cannot safely build on that ambiguous baseline.

## What Changes

- Reconcile or explicitly supersede the remaining maintenance closure items without marking unrun work complete.
- Establish one current observed FlowGuard model-system snapshot from passing v0.11.3 evidence.
- Map the current owners, source/toolchain identities, and maintenance freshness inputs.
- Publish a behavior-neutral patch baseline before bounded-uncertainty work.

## Capabilities

### New Capabilities

- `physicsguard-model-authority-currentness`: Defines current model-owner, snapshot, maintenance-disposition, and toolchain evidence for a feature-ready baseline.

## Impact

Affected surfaces: FlowGuard adoption/model authority, remaining maintenance change dispositions, SkillGuard plan currentness, version/release evidence, and baseline checks.
